⚡ QUICK START (5 MINUTES)

Step 1: Start Services
  cd /workspaces/AiScrumAssistant/scrum-ai-assistant
  docker-compose up -d
  
  ⏳ Wait 30 seconds

Step 2: Initialize Database
  docker-compose exec api alembic upgrade head

Step 3: Verify Everything Works
  curl http://localhost:8000/health

You should see: {"status":"healthy",...}

✅ Done! Your app is running!

🎯 WHAT THIS APP DOES

In simple terms:

Input:  Meeting transcript (text from a meeting)
        ↓
        AI reads it and finds:
        - Decisions made
        - Blockers (problems)
        - Action items (tasks to do)
        ↓
Output: Tasks created in Jira automatically

Example:
  Input:  "Team meeting. Sarah finished login. Decision: Use React Query.
           John blocked on API. Action: Tom complete payment by Friday."
  
  Output: 
    Decisions: [Use React Query]
    Blockers: [API not ready]
    Tasks: [Complete payment integration - assigned to Tom]

🔑 KEY CONCEPTS FOR BEGINNERS

Docker
  - Container = sealed box with everything your app needs
  - docker-compose = start multiple containers with one command
  - You don't install Python, databases separately

API (Application Programming Interface)
  - Way to talk to an application
  - Send request → Get response
  - Like a waiter taking your order

REST
  - GET = ask for information
  - POST = send information
  - Common way to build APIs

JSON
  - Format for data (like a structured text)
  - {"name": "value", "id": 123}

curl
  - Command-line tool to make web requests
  - Test APIs from terminal

❓ COMMON QUESTIONS

Q: Do I need to know Python?
A: No! Docker handles everything. You just need to run commands.

Q: What is Docker?
A: Software that packages the app so you don't need to install everything.

Q: Why use this instead of manual notes?
A: It's automatic! Meeting → AI extracts → Tasks created. Saves time.

Q: How long does it take to learn?
A: 5 minutes to run it. 1 hour to understand everything.

Q: Can I break something?
A: No! You can only run commands. Can't modify code unless you want to.

Q: What if I get an error?
A: Read the error message (usually tells you what's wrong).
   Check logs: docker-compose logs -f api

⚠️ TROUBLESHOOTING

Problem: "Connection refused"
Solution: Wait 60 seconds and try again. Services take time to start.

Problem: "Cannot find docker"
Solution: Install Docker Desktop from https://www.docker.com

Problem: "Port 8000 already in use"
Solution: 
  docker-compose down
  docker-compose up -d

Problem: Test script fails
Solution:
  1. Check if services are running: docker-compose ps
  2. Check logs: docker-compose logs
  3. Make sure you ran: docker-compose exec api alembic upgrade head
